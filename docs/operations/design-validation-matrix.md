# Design Validation Matrix

AP-101 inventories the design surfaces that VA Auto-Pilot claims to support and
maps each one to an executable proof path. A design is not considered validated
by prose alone: each row below has either a concrete command/test entrypoint or
an explicit follow-up task that must close the runtime gap.

## Baseline Gates

Run these before claiming the matrix is current:

```bash
npm run typecheck
npm run check:all
npm run check:e2e
```

For public narrative and release-readiness rows, also run the stale wording scan
from `docs/operations/public-narrative-spec.md` and
`docs/operations/open-source-readiness-checklist.md`.
